# AnnGebra

ANN-Gebra es una aplicación Android desarrollada como herramienta de apoyo para el aprendizaje y resolución de problemas matemáticos. La aplicación reúne diferentes utilidades matemáticas en una interfaz sencilla, permitiendo realizar cálculos de manera rápida desde un dispositivo Android.

📱 Descripción

ANN-Gebra fue desarrollada como un proyecto académico utilizando Android Studio y Java. Su objetivo principal es proporcionar diferentes herramientas para facilitar la resolución de ejercicios relacionados con matemáticas y álgebra.

La aplicación cuenta con diferentes módulos para trabajar con:

🔢 Ecuaciones
📊 Matrices
📐 Vectores
🧮 Operaciones matemáticas

Además, la aplicación permite trabajar con diferentes tipos de números, incluyendo:

Números enteros
Números negativos
Números decimales
Fracciones
⚙️ Funcionalidades
Ecuaciones

Permite resolver sistemas de ecuaciones lineales de:

Sistemas 2 × 2
Sistemas 3 × 3

La aplicación procesa los valores introducidos por el usuario y muestra los resultados correspondientes.

Matrices

Permite introducir matrices y realizar operaciones matemáticas con ellas.

Vectores

Permite trabajar con diferentes vectores y realizar operaciones entre ellos.

El módulo está diseñado para permitir trabajar con una cantidad variable de vectores.
